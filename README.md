# Laboratório das Grandezas

Aula interativa de Matemática para o 8º ano: grandezas direta e inversamente proporcionais, constante k e sentenças algébricas.

**Professor:** Thiago, de Matemática
**Escola:** E.E. Moacyr Amaral

## Acesse

https://thiago-spba.github.io/laboratorio-grandezas-8ano/

## O que tem

- Recados sobre a tarefa e o Matific
- Aula introdutória: grandeza, direta e inversa, o que é o k e sentença algébrica
- 3 experimentos com controles e gráfico
- 4 casos de treino com passo a passo

## Tecnologias

HTML, CSS e JavaScript em um único arquivo (`index.html`), hospedado no GitHub Pages.
